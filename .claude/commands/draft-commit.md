다음 두 명령어를 실행하고 결과를 분석해 커밋 메시지 draft를 작성해줘.

```
git diff --staged
git log --oneline -5
```

커밋 메시지 형식:

```
[type] subject

- 변경 항목 1
- 변경 항목 2
```

type 규칙:
- feat: 새 기능 추가
- fix: 버그 수정
- chore: 빌드/설정/환경 변경 (기능 무관)
- refactor: 동작 변경 없는 코드 구조 개선
- docs: 문서·주석 변경
- style: 포맷·공백 등 코드 스타일만 변경
- test: 테스트 추가 또는 수정

subject 규칙:
- 소문자로 시작 (고유명사 제외)
- 마침표 없음
- 명령형 동사 또는 명사구
- 영어 또는 한국어로 일관되게

body 규칙:
- `- ` 로 시작하는 bullet 항목
- 변경된 파일/모듈 단위로 요약
- "무엇을" 보다 "왜/어떤 목적으로"가 드러나도록
